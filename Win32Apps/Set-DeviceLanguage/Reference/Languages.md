# 🗣️ Languages

All values you can use for `-Language`, taken from the official Microsoft list of Windows language packs and language interface packs.

Source: [Available language packs for Windows](https://learn.microsoft.com/windows-hardware/manufacture/desktop/available-language-packs-for-windows) (Microsoft Learn)  
Retrieved: 2026-11-18  
Back to the [README](../README.md)

> Only the tags on this page work as Windows display language. A language interface pack (LIP) needs its base language installed and falls back to the base language for UI text that is not translated.
